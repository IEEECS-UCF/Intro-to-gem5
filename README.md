# Intro to gem5

This repository contains the slides used for the Intro to gem5 workshop conducted on 11/06/2026.

### Workshop Overview

The session was led by Dr. Derrick Greenspan.

gem5 is an open-source simulator that lets your laptop model a CPU before the silicon exists. The workshop covered why architecture simulation matters, how to get around gem5, and how to write a basic config script to run and measure a simulated system.

### Slides

The workshop used the gem5 project's tutorial slides from HPCA 2024, presented there by Bobby R. Bruce. They were made for gem5 v23.1, so some commands and APIs may differ in newer gem5 releases.
